# 实验协议

## 运行追溯
每次实验独立目录，包含 manifest.json、resolved_config.yaml、command.txt、environment.json、metrics.json、status.json。详见data_schema第7节。数据、模型、轨迹、日志和原始结果放artifacts，不入Git。小型summary可提交，但保留运行时SHA。

开发验证 `formal=false` 可以记录脏状态；正式实验要求已有提交且工作区干净，必须保存实际配置、完整数据/划分/任务清单、种子、checkpoint哈希、环境和命令。配置分类文件是候选规格，未来入口需展开成完整生效配置，不能仅引用路径。

清单工具只负责追溯，不执行模型；metrics初始为空。上下文执行正常/异常分别标记completed/failed；异常继续抛出，不能吞掉失败。保留失败输出，禁止用重试成功覆盖原运行。

## 数据与任务
按回合和地图几何隔离后切窗，版本化划分清单；正常交通训练数据变化几何、流量、路线、驾驶参数、种子。调参/尺度/阈值仅训练与验证集。测试任务预先固定，攻击车—目标车只用t0状态与路线选择；不利用真实未来退出时间。

评估被选车辆集，记录未选车辆数。不完整标签、失败、过滤理由和数量均保存。SUMO仅支持仿真内结论，播放不是动力学或闭环证明。

## 比较与独立指标（后续阶段）
base、固定引导、阶段日程、状态规则共用checkpoint、任务、初始噪声、DDIM步数和设置；同时比较相同步数、相同实际引导预算。记录真正发生的梯度调用，不能以配置里的最大次数替代。

目标碰撞与有效目标事件、非目标碰撞、车身道路/路线/地图覆盖、运动及历史未来边界、解码/引导修正、耗时和峰值显存分别报告。碰撞含帧间插值，无适用车辆对N/A；生成失败和质量不合格样本留在预定分母。没有旧综合分数。

质量阈值与校准来源固化后再测试。保留原始输出、统一解码、引导输出各阶段统计，不用只看平滑后指标掩盖原始质量。配对差值和置信区间按独立episode/geometry组处理，不能将重叠窗口视作完全独立样本。
