# 三维控制目标接入与有界校准结果

交付日期：2026-10-14。

已在原train、calibrate、sample入口接入三维控制目标及公共可微回放，完成短训练、完整组合梯度和真实GPU恢复验证。**这次验证支持接口与有界学习链路可运行；尚无合格的新控制生成模型。** 16次更新后的3个自由采样任务全部触发角增量保护，原始输出与失败分母已保留。

## 实现内容

新模型未来输出40点[a,omega,r]，历史仍为21点六维状态；使用已冻结尺度2 m/s²、0.5 rad/s、0.1 m/s。新schema明确区分三维控制与旧六维状态，旧200轮模型保留作基线，不能继承为新控制头。数据文件、坐标与质量阈值保持。

训练标签只在离线反解时读取未来。训练辅助监督与采样共用中心／区间中点float64回放；回放后中心位置差分定义速度。没有额外平滑或最小二乘协调。原始三维输出单独保存；六维raw／decoded状态都是回放状态，零修正只表示没有后处理阶段，不是质量改善证据。

辅助目标为配对回放状态的模仿0.003、全40帧时间差分0.001、道路／路线0.001及物理jerk尾部0.0003，均为候选；保留低t<=300、alpha_bar及共同预热。取消旧六维原始速度头的二阶差分监督，原因是新控制头不直接预测速度。权重仍需未来固定数据协议下校准，不能称为最优设计。

短配置使用原显式28训练／28验证诊断任务、batch4、16更新，随机初始化新模型和AdamW；不继承旧模型策略。原CLI可恢复训练，完整预算、日程及任务清单哈希锁定，prefix不会重启日程。本阶段配置上限64更新，正式长训练协议尚未实现。

独立CPU审计覆盖训练28窗／143车辆窗口、验证28窗／199车辆窗口，共56窗／342车辆窗口。训练目标经过float32归一化后重新回放：

| 核对项 | 最大误差 |
| --- | ---: |
| 标签位置恢复 | 1.23e-7 m |
| 标签速度恢复 | 7.39e-5 m/s |
| sin/cos分量恢复 | 3.15e-8 |
| 独立NumPy与Torch回放状态 | 1.42e-13 |

速度误差包含原float32标签速度与中心位置差分的舍入残差。对应门槛位置1e-5 m、速度0.001 m/s、朝向分量1e-6、独立状态1e-9，均通过。这证明标签变换与回放数值一致，不证明自由生成质量。

第一次真实GPU校准在PyTorch 2.5.1严格确定性模式下因CUDA cumsum不受支持而失败，来源保留。修复采用固定下三角线性映射实现同一前缀和，没有关闭确定性或使用warn_only；真实CUDA数值与反向测试通过，恢复运行也逐位一致。

## 完整组合梯度

初始化和16更新后各11组探针：三类普通、密集无转弯、转弯组，分别自然随机t与固定t=200；另有B16密集／转弯探针。仅加载训练标签，所有分项、组合辅助梯度和总梯度分别实际求导，每状态67次梯度调用。

| 量 | 初始化 | 16更新后 |
| --- | ---: | ---: |
| 组合辅助／噪声范数最大比例 | 14.62% | 10.19% |
| 总梯度／噪声梯度余弦最低值 | 0.992205 | 0.995749 |
| 组合梯度相对残差最大值 | 6.60e-7 | 6.93e-7 |
| 将触发裁剪的探针 | 11/11 | 11/11 |
| 非有限值 | 0 | 0 |
| 探针主体时间 | 8.38 s | 6.77 s |

分项范数比例没有相加。两次探针参数哈希前后不变，未更新优化器、未实际裁剪。自然随机t有组没有低噪声合格场景，此时辅助梯度为0，余弦N/A；保留记录，不当作辅助目标通过率。

结果表明当前检查点的组合梯度数值可用、方向接近噪声目标；不能据此证明候选权重最优或充分训练后生成改善。阈值1.0会裁剪这些随机初始化附近的总梯度，真实短训练也记录16/16次裁剪；无需为了制造“不裁剪”结果修改阈值。

| 更新数 | 固定训练探针MSE | 固定验证探针MSE |
| --- | ---: | ---: |
| 0 | 1.058925 | 1.059090 |
| 8 | 0.728205 | 0.730960 |
| 16 | 0.667098 | 0.670197 |

固定训练探针下降约37.0%，支持短预算下能够学习。未设置或执行收敛判定，不能将新三维噪声MSE直接与旧六维模型数值比较。

完整16更新与独立8+8恢复对照全部通过：训练签名、最终步数、模型权重、AdamW、噪声Generator、CPU/CUDA RNG、更新日程和逐步完整损失记录一致。恢复后的8次更新实际比较包含学习率、辅助预热、总loss、各分项和裁剪标记。三个训练运行实际合计32次优化更新，其中16次属于重复恢复验收，不是额外训练后的32步模型。

## 自由采样的负结果

三个验证任务各20步DDIM，实际去噪调用60、梯度调用0。三个任务都在回放时因单步航向增量不满足严格小于pi的条件而失败；确认通过0/3，失败仍保留全部分母。该保护未放宽，没有裁剪、投影或重采成功样本覆盖失败。

| 道路 | 预测a绝对最大 (m/s²) | omega绝对最大 (rad/s) | r绝对最大 (m/s) |
| --- | ---: | ---: | ---: |
| 直路 | 822.258 | 139.060 | 32.555 |
| 汇入 | 714.014 | 192.780 | 36.362 |
| 路口 | 841.698 | 158.388 | 31.289 |

原始控制有限但严重不合理，因此没有生成可供独立道路、碰撞或舒适性评价的六维轨迹；这些未知质量不能伪造为0违规。第一次采样已保留失败；补齐实际调用计数后的复核与第一次初始噪声和原始控制逐元素相同，两次各3失败，不是6个独立任务。

16更新不足以据此否定新表示；同样也不能将MSE下降当作采样质量通过。当前结论是“表示与训练／恢复工程检查完成，生成质量未建立”，不自动扩大训练预算。
