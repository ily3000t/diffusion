# 正常交通源头与当前参考选择：小规模对照结果

本阶段已完成实现和实测。直路SL2015候选降低换道上下文jerk，并产生合格换道窗口；汇入必须同时处理连接几何，仅换SL2015不够。当前EIDM候选使路口jerk尾部变差，不建议采用为默认。交互参考增加汇入／转弯覆盖，但会减少部分主路换道覆盖，应保留两种策略并按运动类别核对。

这还不是最终数据配方：汇入候选仍有大面积车身越界和纵向突变，需要继续做源头小验证，不能据此立即重建正式数据或启动长训练。完整冻结协议见[source_motion_pilot.md](source_motion_pilot.md)，轻量数值与文件身份见[source_motion_results.json](source_motion_results.json)。

## 已执行范围与可比性

固定14个训练专用短回合：七种配置×两种子；需求30s、排空上限240s，全部完整排空且通过原采集级正常交通检查，没有碰撞、teleport等采集异常。该检查不等于逐窗物理质量通过。

每回合最多32个当前全局至少2车的参考时刻，对旧参考和interaction_current两策略使用相同清单，合计896个详细质量记录。每个道路／配置／策略的分母均为64。其余全部候选只检查选车与事件覆盖，未评估质量保持unknown。模型改变会改变实际轨迹和回合时长，因此不同仿真配置的参考时刻清单不保证相同，不能把本结果称为严格逐轨迹配对收益。

所有质量门槛保持原值：完整历史／未来、原始float64与存储float32、完整有向车身道路／路线及帧间碰撞检查。没有平滑标签、降低jerk15门槛或放宽几何容差。正式6000/600/600数据、旧200轮checkpoint及训练目标未修改。

## 原始运动变化

以下为两种子各自P99及最大值的范围，单位m/s³；不是置信区间，也没有先平均分位数。直路取换道事件前后3s，汇入取退出前8s至后1s，路口取中心60m内。事件上下文可能重叠；上下文不足的事件通过状态为N/A。不同区域与运动不能直接横向排名。

| 道路／配置 | 原始中心jerk P99范围 | 原始中心jerk最大值范围 |
| --- | ---: | ---: |
| 直路 baseline | 58.72—58.78 | 58.83—59.01 |
| 直路 SL2015 | 2.66—2.69 | 3.36—4.87 |
| 汇入 baseline | 151.90—166.77 | 164.79—180.93 |
| 汇入 SL2015 | 156.58—164.95 | 184.48—205.61 |
| 汇入 SL2015＋80m过渡 | 0.78—0.92 | 1.15—1.15 |
| 路口 IDM baseline | 8.06—9.03 | 40.00—40.02 |
| 路口 EIDM | 13.62—20.72 | 55.11—55.36 |

SL2015使用lcAccelLat=0.3、maxSpeedLat=0.8、分辨率车道宽/4；旧配置为LC2013持续3s换道。本次数据支持其改善直路横向运动，而不是从参数名字推断质量。原始换道事件数也从13变为11，不能声称行为频率完全不变。

汇入仅换SL2015时，另一个换道上下文甚至出现3512.71的中心jerk，发生在:merge_end_0，而同刻报告纵向jerk约2.76e-6。不能将该候选认定为可用。80m五次曲线连接及对齐匝道入口后，匝道退出上下文明显改善；两种子原始匝道退出事件均保持3个，总计6个。不过其他换道上下文仍有25.20／55.11的峰值，不能用退出区域P99低就宣布整个回合合格。

路口EIDM的约55峰值与报告纵向加速度变化吻合：低速约0.25m/s时，某车加速度由约−3.57变为+1.94m/s²。jerkmax=3不是此次所有状态变化的硬上限。即使部分选定窗口合格数增加，也不能忽略全区域尾部恶化。本轮保留EIDM负结果，后续优先沿用IDM检查源纵向变化。

## 合格窗口与事件覆盖

每格“旧／交互”为两参考策略；每项均在该配置两回合、每策略64个详细窗口中计算。指定运动：直路为日志确认换道，汇入为协议定义匝道退出，路口为未来航向范围>=5°。窗口重叠，不能当作独立事件。

| 道路／配置 | 全部合格窗：旧／交互 | 指定运动合格窗：旧／交互 | 合格窗覆盖唯一事件：旧／交互 |
| --- | ---: | ---: | ---: |
| 直路 baseline | 19／27 | 0／0 | 换道0／0 |
| 直路 SL2015 | 33／45 | 6／7 | 换道4／4 |
| 汇入 baseline | 15／12 | 0／0 | 退出0／0 |
| 汇入 SL2015 | 17／16 | 0／0 | 退出0／0 |
| 汇入 SL2015＋80m过渡 | 33／39 | 2／5 | 退出2／4 |
| 路口 IDM baseline | 36／42 | 2／8 | N/A，未定义离散转弯事件 |
| 路口 EIDM | 38／47 | 4／11 | N/A，未定义离散转弯事件 |

上述唯一事件只表示“在详细评估合格窗中观察到”，不是全回合合格事件总量。两参考策略的事件可重叠，不能相加。例如直路SL2015两者均4，不代表8个不同事件。

在全部参考时刻的轻量覆盖中，baseline汇入退出由旧参考2个提高到交互参考6个，但没有任何已评估合格退出事件。结合几何候选后才出现上表2／4个合格事件，支持任务选择与源轨迹质量需要同时处理。

交互参考不是所有类别都更好：汇入几何候选的合格主路换道唯一事件由旧参考3降为交互参考2，少覆盖flow_main.2在16.9s的事件。今后应保留两种任务来源，在同一划分内去重并设分开的换道／汇入／转弯配额，不能用单一交互参考替代全部窗口。车辆槽位、固定局部系及最多12车保持；策略只读当前状态、地图和已知路线，未来标签未进入条件。

## 残余道路问题，不能用放宽阈值解决

汇入几何候选的交互参考64窗中仍有8窗道路及路线拒绝、6窗运动拒绝，原因有重叠；另有12窗标签不完整。世界坐标独立车身检查核实这8个道路拒绝窗，去重为26个车辆—时刻违规帧：

- 5个窗口的最大越界面积约2.05e-5m²，出现在匝道入口至加速段的几何拼接附近，应继续检查连接与车身覆盖。
- 其余3个窗口最大越界约0.396或3.141m²。示例flow_main.2已进入main_out_0，仍有−1.455m横向位置偏移，中心约[222.44,−10.27]；这不是可以忽略的数值误差。

原质量拒绝全部保留。下一步应检查加速车道的合法换道权限、车辆带横向偏移进入内部连接的条件及出口对齐；这些是待验证的修正方向，尚未证明某参数就能消除问题。不能通过扩大可通行区或几何容差来把现有失败改成通过。
