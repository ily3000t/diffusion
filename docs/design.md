# SUMO 多车轨迹扩散生成：第一版设计

本文件是实施合同，描述目标接口；实现状态以 `progress.md` 为准。阶段 0 只实现工程和实验追溯，不代表下述算法已经完成。

## 1. 数据和任务定位
使用 SUMO 生成正常交通数据，训练固定时域的离线多车联合生成模型，危险交互由采样引导增强。保留 `base` 和 `guided` 入口，`diffscene_style` 是引导入口的兼容名称。取消旧高速公路积分器、旧综合评分及其他旧训练模式。新状态表示必须重新训练基础模型，旧 checkpoint 不兼容。

SUMO 数据支持仿真场景内验证，不能单独证明真实驾驶行为真实性。轨迹写回 SUMO 仅用于播放检查，播放成功不等于动力学执行或闭环攻击成功。

| 项目 | 第一版范围 |
|---|---|
| 道路 | 三车道直路、匝道汇入、无信号路口 |
| 变化 | 每类多组几何；变化流量、路线、驾驶参数、种子 |
| 车辆 | 乘用车 |
| 任务 | 联合生成参考时刻已存在的选定车辆 |
| 排除 | 未来车辆出生、行人、自行车、信号控制、闭环攻击、任意长度生成 |
| 扩展 | CFG、部分扩散、滚动生成、引导控制器；默认关闭 |

未实现的扩展或 checkpoint 不支持的能力，启用时必须明确报错，不静默降级。当前可运行命令只在 README 列出；阶段 0 不提供虚假的模型入口。

## 2. 数据、时间和坐标
完整回合可变长，训练窗口固定。先按回合和地图几何划分，再切窗。所有尺度检查、阈值校准和参数选择只使用训练与验证集。

| 接口 | 约定 |
|---|---|
| 采样间隔 | dt = 0.1 s |
| 历史 | 2 s，21 点，包含 t0 |
| 未来 | 4 s，40 点，自 t0 + dt 开始 |
| t0 间隔 | 初始 1 s |
| 车辆上限 | 初始 12，包括参考车辆 |
| 历史状态 | x, y, vx, vy, sinψ, cosψ |
| 未来状态 | Δx, Δy, vx, vy, sinψ, cosψ |
| 属性 | 长、宽、类型、参考车辆标记 |
| 意图 | 每辆车在 t0 已知的计划路线 |
| 地图 | 栅格、车道折线、连接、通行规则 |
| 掩码 | agent_mask、history_mask、标签 future_mask |

参考车辆在 t0 的几何中心和数学角度确定唯一固定局部坐标系。整个窗口不移动或旋转它，历史、未来、其他车辆、路线、地图都使用同一变换。未来 Δx/Δy 相对于各车 t0 的位置，方向仍在共同局部系。

SUMO 前保险杠位置、导航角先转换为几何中心、数学角度，保留全部原始字段以核对。二维速度统一由几何中心位置后向差分定义，表示一个采样区间的平均速度。历史第一点需额外前一原始点；禁止用未来位置生成历史特征。

选择车辆仅依据 t0 当前状态与已知路线，窗口中 ID 和槽位保持不变。入口、出口设置足够缓冲区，核心训练优先用未来标签完整的窗口；不完整窗口保留、计数并记录原因。真实未来退出时刻只能用于标签有效性，不能作为推理条件。

当前 GPU 约 8GB。车辆数、网络大小、batch size 都是候选，必须以单批前后向实测决定，不能保证预设 batch size。

## 3. 地图分工
- CNN 栅格表示可通行区域、边界、中心线；初始 256×256，通道不绑定车辆槽位。
- 折线表示方向、宽度、限速、合法连接、路口内部连接和优先通行关系。
- 精确道路约束用几何信息，不只依赖低分辨率栅格。
- 物理覆盖范围根据速度、预测时域和被选车辆范围检查后冻结；超出地图覆盖与驶出道路分别报告。
- 各车路线走廊根据 t0 已知计划路线和合法连接构造，允许合法换道。

## 4. 条件编码和网络
逐车历史 → 共享时间 CNN → 历史特征。
逐车路线和地图 → 道路条件交叉注意力。
道路条件下的车辆特征 → 车辆交互注意力。
历史、道路、交互特征 → 逐车门控融合。
逐车条件 → 共享时间 U-Net，瓶颈按未来时间索引做车辆注意力 → 噪声预测。

| 张量 | 形状 |
|---|---|
| history | [B, N, 21, 6] |
| noisy_future | [B, N, 40, 6] |
| condition | [B, N, 128] |
| pred_noise | [B, N, 40, 6] |

初始条件维度 128、4 个注意力头，各融合阶段 1 层。保留 `hierarchical` 与 `parallel`，共用编码器与扩散主干，以便定位融合设计作用。所有注意力、编码和输出必须处理掩码；验证车辆重排一致性和无效槽位不影响有效车辆。

基础模型不含攻击角色嵌入。参考车辆标记用于坐标和条件，攻击角色由采样任务指定。层次融合是架构选择，是否构成有效贡献须由对照结果支持。

## 5. 扩散和统一解码
| 项目 | 初始约定 |
|---|---|
| 位置尺度 | 50 m 候选，训练/验证数据检查后冻结 |
| 速度尺度 | 20 m/s 候选，检查后冻结 |
| 朝向 | sin/cos 不做逐场景标准化 |
| 目标 | 预测噪声 ε |
| 损失 | 每场景按有效元素归一化的掩码噪声 MSE |
| 采样 | DDIM，20 步、eta=0 候选 |
| 附加训练损失 | 默认关闭，依据原始误差再决定 |

基础与引导使用同一解码器。固定观测起点，以可微最小二乘协调预测位置与速度，再以最终位置后向差分定义最终速度。线性求解用合适精度，不直接在半精度下求解。sin/cos 规范化，近零向量使用明确回退并计数。

必须分别保存原始预测、解码轨迹、引导轨迹及各阶段修正幅度。基础采样没有引导阶段时明确标记不适用，不伪造一次引导。协调只保证定义的位置—速度一致性，不保证动力学可行或道路合规；历史—未来边界的加速度、jerk、朝向变化独立检查。

## 6. 固定目标引导
生成前依据当前状态和已知路线固定一目标、一攻击车；无适用车辆对则记录。目标风险梯度仅直接调整攻击车，约束修复可以调整相关生成车辆。扩散主干冻结，梯度经统一解码器传到干净状态变量。

| 项 | 定义 |
|---|---|
| 目标风险 | 二维有向车身平滑分离裕度，时间聚合；接触后收益逐渐饱和 |
| 非目标安全 | 除指定目标—攻击车对外的全部车辆对 |
| 道路与路线 | 车身通行区域、允许路线走廊，允许合法换道 |
| 运动 | 速度、纵横向加速度、jerk、明显朝向—运动矛盾 |
| 局部偏移 | 相对本步未引导预测限制修正，内循环参考固定 |

风险与约束基于同一解码轨迹，先无量纲化再组合。更新干净状态后，DDIM 转移必须重算与更新状态对应的噪声表示。不能把几何代理量称为碰撞概率。

## 7. 独立评估和公平比较
报告目标碰撞率、满足质量条件的有效目标事件率、非目标碰撞率；道路、路线、覆盖问题；原始运动质量和历史—未来边界变化；解码/引导修正；生成时间、实际梯度调用次数、峰值显存。

碰撞检查包含帧间插值。无适用车辆对输出 N/A；失败和质量不合格样本保留在预定分母。评估范围为选定车辆，记录未纳入车辆数量。未来 RL 的训练奖励独立于论文指标，不输出旧综合场景分数。

base 和引导共用 checkpoint、任务、初始噪声、DDIM 设置。对照固定引导、按去噪阶段日程、简单状态规则；分别比较相同步数及相同实际引导预算。报告配对差值与置信区间，测试集不调参。

## 9. 可选研究：预算下的引导控制
阶段 7 后才决定阶段 8。冻结扩散主干，小型策略选择跳过、目标风险增强、非目标安全修复、道路路线修复、运动修复。观察包含当前解码轨迹摘要、去噪进度、最近效果和剩余预算。PPO 仅用控制器自身动作概率，不沿用旧 DDPO 轨迹概率比。

保存观察、动作、概率、奖励、成本、完整采样清单。先短验证，再与固定引导、阶段日程、状态规则、等预算参数搜索比较，报告质量与实际计算成本。无收益则保留负结果，不自动扩大规模。

研究问题是在固定计算预算下，如何按生成状态选择风险增强和约束修复。加入 PPO、改变权重、组合 CNN/Transformer 本身不足以自动形成新贡献。

## 10. 阶段2已落地选择

固定参考系、后向中心速度、21/40点窗口、t0稳定选择、未来标签隔离与几何分组已实现。当前采用first_current_id参考、80m邻域、N≤12；三通道栅格范围±192m，车道64点。覆盖设计包络25m/s在train/validation核对，不使用test调参；状态尚未归一化。

完整已知计划路线保留全部同edge乘用车车道及合法内部连接链，路线index以t0观测另存。道路约束的向量约定、零长度内部车道处理和普通/内部junction规则分工见window_dataset。核心训练窗要求所选车辆历史与未来均完整；其余窗和排除理由保留，推理不按标签完整性过滤。

本次九正常回合只验证三划分和三类别覆盖；正式训练数据与任务协议未建立。阶段3已实现统一解码器与独立指标，验收状态及限制见progress和decoding_evaluation；阶段4已实现共享条件/融合/联合噪声网络，接口见conditional_model、验收见progress；阶段5训练/扩散采样尚未实现。
