## 3. 条件重构也有高频误差

读取48个训练窗（各道路16个）和全部200验证窗，向真实未来标签加同一逐窗Gaussian噪声，逐个训练噪声索引t检查干净状态恢复。**t=50是扩散噪声索引，不是50步DDIM。** 以下“通过”只检查解码后运动，不含道路或碰撞，不能称场景质量通过。

| 噪声索引t | 训练运动通过/48 | 验证运动通过/200 | 训练内部jerk P99 | 验证内部jerk P99 | 验证原始速度误差P99，m/s |
|---|---:|---:|---:|---:|---:|
| 0 | 24 | 111 | 28.10 | 34.48 | 0.225 |
| 50 | 0 | 0 | 96.77 | 108.32 | 1.374 |
| 100 | 0 | 0 | 121.99 | 145.61 | 1.842 |
| 200 | 0 | 0 | 158.50 | 180.86 | 2.355 |
| 300 | 0 | 0 | 219.58 | 236.53 | 2.667 |

所有对应正常标签控制的运动检查均通过。训练与验证都有问题，因此不能把残余jerk只解释为验证集泛化或DDIM采样链路误差；本次20步bitwise重放也未发现代码复现问题。

验证epsilon MSE在t=0/50/100/200/300为0.03105/0.002017/0.000888/0.000352/0.000190。它随噪声索引下降时，物理运动误差并未同步下降：干净状态恢复有sqrt((1−alpha)/alpha)的尺度变化，速度还有20m/s反归一化及dt²差分放大。不能把不同t的epsilon MSE直接当作同等物理误差，或用总体随机t验证MSE代替时间质量。

当前原始速度误差经一致性协调后，速度差分与jerk仍可超限。结合上一轮字段oracle（模型位置/真实速度P99=13.81、真实位置/模型速度=95.46），原始速度时间约束是有明确证据的下一步候选。标签重构和oracle仍不是可实现的自由生成改善。

## 4. 当前模型的分项梯度

训练集16批B4共64个不重复窗口，ID与噪声Generator来自假设的下一轮起点；没有训练或优化器更新。自然随机t中10批存在适用场景，同噪声强制t=200中16批均适用。梯度在eval模式和局部补齐的B4上测量，不冒充原缓存训练的bitwise下一步执行。

以下为各项参数梯度范数/epsilon项范数的中位数（最大值）。当前加权项使用已训练配置；原始速度候选项是未加权诊断Huber，不是已实施的新训练loss。

| 项 | 自然随机t，适用10批 | 强制t=200，16批 |
|---|---:|---:|
| 当前模仿项 | 0.706（1.845） | 1.271（3.788） |
| 当前解码时间项 | 0.074（0.219） | 0.072（0.156） |
| 当前总辅助项 | 0.725（1.851） | 1.285（3.807） |
| 当前道路项 | 0（0） | 0（0.047） |
| 原始速度二阶差分，内部 | 3185.9（9203.4） | 2743.6（6493.2） |
| 原始速度二阶差分，前4帧 | 5045.6（26921.2） | 6778.7（13289.4） |

候选二阶差分以0.15m/s归一化，对应dt=0.1s下15m/s³的误差尺度，保留t<=300、alpha_bar及每场景/全batch分母。它监督与正常标签的差，不强制jerk为零，也不保证满足硬阈值。当前时间项约7%的相对梯度不能证明它无作用，但支持比模仿项更弱。当前模仿梯度已比父模型校准时更大，加新项必须在45000步模型上重新审计，不能沿用父模型梯度比例。

**若把现有0.001权重直接用于新原始二阶差分项，单项梯度中位数就会达到epsilon的约3—7倍，部分批次远高于此。** 应使用更小系数并审查组合梯度。

待审起始尺度可取内部5e−5、前4帧1e−5：线性换算自然t单项梯度比中位数约0.159/0.050，最大0.460/0.269；强制t=200中位0.137/0.068，最大0.325/0.133。它们是同一冻结参数上单项尺度换算，未测新目标联合更新效果，未作为生产配置实施，也不是正式训练推荐的最终参数。仍需组合梯度与有界训练检查，保留现有模仿/道路目标及其质量监测。
